# 🤝 Contributing to Face Age Prediction

Thank you for your interest in contributing to this project!  
Please follow the guidelines below to ensure a smooth contribution process.

## 🛠️ How to Contribute

1. **Fork** the repository.
2. **Clone** your fork:
   ```bash
   git clone https://github.com/zakariaelaoufi/face-age-prediction.git
   ```
3. **Create a branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes**:
   - Write clean, well-structured, and documented code.
5. **Test** your changes locally.
6. **Commit** with a meaningful message:
   ```bash
   git commit -m "Add: short description of your change"
   ```
7. **Push** to your branch:
   ```bash
   git push origin feature/your-feature-name
   ```
8. **Create a Pull Request** with a clear explanation of what you’ve done.

## ✅ Code Style

- Follow **PEP8** (Python coding style guide).
- Use meaningful variable/function names.
- Keep functions small and focused.
- Include comments where necessary.

## 💡 Suggestions

If you have ideas or find bugs, feel free to [open an issue](https://github.com/zakariaelaoufi/face-age-prediction/issues).

*Happy coding!*
